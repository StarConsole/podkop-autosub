# Podkop Auto-Sub (podkop-autosub)

Automated key rotation and health monitoring tool for Podkop proxy on OpenWrt.

## Features
- Dynamic subscription fetching and filtering (VLESS/Reality).
- Health checks (Ping, YouTube 204, Gemini accessibility).
- OpenWrt UCI configuration support.
- Telegram status notifications.

## Quick Installation

Run this command on your OpenWrt router via SSH:

`curl -sSL https://raw.githubusercontent.com/StarConsole/podkop-autosub/main/install.sh | sh`
