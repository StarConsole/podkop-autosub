# Podkop Auto-Sub (podkop-autosub)

[English](README.md) | **Русский**

Автоматическая ротация ключей и мониторинг состояния для прокси Podkop на OpenWrt.

## Возможности
- Автоматическое скачивание и фильтрация подписок (VLESS/Reality).
- Проверка доступности сети (Ping, YouTube 204, доступ к Gemini).
- Полная интеграция с конфигурацией UCI OpenWrt.
- Уведомления о статусе в Telegram.

## Быстрая установка

Выполните эту команду на вашем роутере OpenWrt по SSH:

`curl -sSL https://raw.githubusercontent.com/StarConsole/podkop-autosub/main/install.sh | sh`
